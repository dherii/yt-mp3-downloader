# 🎵 BaixarMusicas GUI (YouTube para MP3)

Um aplicativo moderno, rápido e simples para baixar áudios do YouTube no formato MP3. Desenvolvido em Python utilizando a biblioteca **CustomTkinter** para uma interface fluida em Dark Mode, e o poderoso **yt-dlp** para o processamento dos vídeos.

## ✨ Funcionalidades

- **Interface Moderna:** Design responsivo com suporte a Dark Mode.
- **Processamento em Segundo Plano:** A interface não trava durante os downloads (Multithreading).
- **Controle Total:** Escolha exatamente em qual pasta deseja salvar suas músicas.
- **Feedback em Tempo Real:** Barra de progresso dupla (arquivos totais e progresso individual).
- **Cancelamento Seguro:** Pare um download no meio do caminho sem corromper o sistema.
- **Pronto para Uso (Standalone):** Executável `.exe` único para Windows, sem necessidade de instalar o Python.

## 📥 Como baixar e usar (Para Usuários)

O aplicativo é empacotado automaticamente para Windows. Para baixar a versão mais recente:

1. Vá até a aba [**Actions**](../../actions) aqui no repositório.
2. Clique na execução mais recente com um ícone verde de sucesso (✅).
3. Role a página até o final, até encontrar a seção **Artifacts**.
4. Clique em `BaixarMusicas-Windows` para fazer o download do arquivo `.zip`.
5. Extraia o arquivo baixado e execute o `BaixarMusicas.exe`.

> **Aviso:** O GitHub exige que você esteja logado em uma conta para conseguir baixar arquivos da aba Artifacts.
